## [1.3.7]

Изменено:

- **Бэкенд разбит на модули.** Монолитный `/usr/bin/vless` (около 1550 строк) стал небольшим диспетчером, а логика
  разложена по `root/usr/share/vless/lib/*.sh`: `util`, `validate`, `settings`, `discord`, `cron`, `subscriptions`,
  `lifecycle`, `net`, `selective`, `probe`, `status`. Поведение не менялось: набор функций и их тела прежние.
  Описание модулей — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- **Секрет Clash API больше не в `argv`.** `api()` передаёт `Authorization: Bearer …` в `curl` через stdin (`-K -`),
  поэтому секрет не виден в `/proc/*/cmdline`.
- **Прямой пинг не ходит через прокси.** `ping_one_direct` вызывает `curl --noproxy '*'`.
- `install.sh` проверяет, что все модули скопированы, и откатывается, если нет.

Добавлено:

- Тест `tests/modules.sh`: состав модулей, дубли функций, команды диспетчера, список в `install.sh`.
- Тест `tests/mock-drift.sh`: заглушки `curl` и `uci` не расходятся с кодом (маршруты Clash API и подкоманды `uci`).
- `ci/minify-js.sh` и CI-задача «Размер и минификация интерфейса»: бюджет размера `main.js` и проверка, что
  минификация сохраняет директивы `'require …'`. Минифицированную сборку можно получить так: `MINIFY=1 sh build.sh`
  (по умолчанию релиз не минифицируется).
- Документация: [CONTRIBUTING.md](CONTRIBUTING.md), [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [README.en.md](README.en.md),
  шаблоны issue и pull request.

## [1.3.5]

Исправления:

- **Прямой пинг работает с Reality и серверами без HTTP.** Раньше `curl` без `-k` падал на сертификате сайта-маскировки, а любой ненулевой код выхода обнулял результат. Теперь замер — это время TCP connect: сервер считается живым, если ответил по HTTP (любой код) или закрыл соединение уже после TLS-рукопожатия. Сброс до конца рукопожатия (так выглядит блокировка) по-прежнему считается недоступностью. IPv6-адреса в URL берутся в скобки.
- **`state` не падает от битого `delays.json`.** Раньше проверялась пустая переменная, а не файл.
- **Один `net_up` вместо нескольких при быстром респауне sing-box.** Старый `net_up` останавливается, только если pid действительно принадлежит нашему скрипту.
- **Остатки DNS-настройки.** `init.d` убирает забытый `vless.conf` и перезапускает dnsmasq (одного удаления файла мало); `uninstall.sh` делает то же.
- **VMess + gRPC:** имя сервиса берётся из `serviceName`, а при его отсутствии или пустом значении — из `path`.
- **`install.sh`:** при обрыве копирования возвращается прежняя версия (раньше запускался `uninstall.sh` и пропадали настройки); VPN, который работал до обновления, запускается снова; `nftables` ставится вместе с остальным; есть предупреждение, если dnsmasq собран без `nftset`.
- **`uninstall.sh --purge`** для symlink/mount очищает каталог рекурсивно.
- **`INSTALL.bat`:** код возврата `tar` проверяется сразу после архивации.

Тесты: добавлены проверки `ping_one_direct` (`sh tests/run.sh`).

## [1.3.4]

Исправления:

- **Прямой пинг честнее.** `curl` возвращал `time_connect` даже при HTTP 4xx/5xx — недоступный сервер мог получить «правдоподобный» пинг. Теперь проверяется HTTP-код ответа (только 2xx/3xx считаются успехом).
- **`sysctl rp_filter` не падает.** На некоторых ядрах/контейнерах запись в `net.ipv4.conf.vless0.rp_filter` требует прав, которых нет — ошибка теперь игнорируется (`|| true`).
- **Поддержка множественных секций dnsmasq.** `dnsmasq_dir()` теперь перебирает все секции `dhcp.*.dnsmasq` и находит первый существующий каталог — работает с именованными секциями и `@dnsmasq[0]`.
- **Robust проверка `nftset`.** `dnsmasq --version` парсится через `tr " \t" "\n"` — не ломается на нестандартном выводе версии.
- **Таймаут `cmd_check` увеличен.** `T=12` (было 9) — больше `timeout=7000` в URL, curl не обрывает запрос раньше sing-box.
- **Безопасный цикл `cmd_refresh`.** `while read` вместо `for in $ids` — защита от word splitting.
- **Принудительное завершение зависшего `net_up`.** `net_down` теперь делает `kill -KILL` через 45с ожидания, иначе `stop` висел бесконечно.
- **`cmd_selftest` умнее.** Проверяет версию `jq` (нужен 1.6+ для `walk()` в `build.jq clean`) и делает быстрый запрос к `gstatic.com` — показывает реальное состояние интернета.
- **`uninstall.sh --purge`: защита от symlink/mount.** Перед `rm -rf /etc/vless` проверяет `-L` и `mountpoint -q` — удаляет только содержимое, не цель монтирования.
- **`rpcd/vless`: логирование ошибок бэкенда.** stderr теперь пишется в `$RUN/rpcd.err` и дублируется в `logger -t vless` — ошибки не теряются.
- **Ограничение параллельности в `ping_direct`.** Используется `join_jobs` (макс 8) — защита от OOM на больших подписках.

Установка и сборка:

- Версия в `VERSION` обновлена до `1.3.4`.
- Все изменения покрыты тестами: `sh tests/run.sh` проходит (core-тесты: парсинг, конфиг, пресеты, добавление/удаление, base64, логи, rpcd, ACL).
