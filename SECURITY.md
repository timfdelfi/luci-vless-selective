# Политика безопасности

Приложение работает на роутере под root и хранит ключи и токены подписок, поэтому о проблемах безопасности
просим сообщать приватно.

## Как сообщить

Откройте приватное уведомление на GitHub: **Security → Report a vulnerability** в репозитории.
Не публикуйте уязвимость, свои ссылки (`vless://…`), токены подписок и HWID в обычных issue.

Ответ — в течение нескольких дней; исправление выходит в ближайшем патч-релизе, в `CHANGELOG.md` оно
помечается как «Безопасность».

## Поддерживаемые версии

Исправления выпускаются для последней версии (см. `VERSION`).

## Что проверяется при установке

- архив релиза сверяется с `SHA256SUMS` из того же релиза (защита от битой загрузки; закрепить версию можно
  переменной `VLESS_VERSION`);
- официальный `sing-box` скачивается с GitHub Releases и сверяется с sha256 из GitHub API; без совпадения
  архив не ставится (тег закрепляется переменной `VLESS_SINGBOX_TAG`);
- для максимальной уверенности сверяйте `.sha256` вручную и устанавливайте из архива конкретного релиза.

Это защищает от повреждённой загрузки и подмены файла в пути, но не от компрометации самого репозитория
или аккаунта GitHub.
